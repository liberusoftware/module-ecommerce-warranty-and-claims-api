# `liberusoftware/module-ecommerce-warranty-and-claims-api`

Optional HTTP adapter for the Warranty and Claims core module. It exposes the versioned Sanctum-protected `/api/v1/ecommerce/warranty-and-claims` contract and delegates mutations to core actions.

The OpenAPI 3.1 fragment is in `openapi/v1/ecommerce-warranty-and-claims.yaml`.
